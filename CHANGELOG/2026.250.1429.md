# 2026.250.1429 — feat: add the adb session method (plan Cutover E, E-4)

## Summary

Adds the `session` method to the `adb` verb (plan `nested-capture-architecture.md`, Cutover E, unit 4): the **on-device screenrecord bracket** — `screenrecord` started on the device at phase start, stopped (SIGINT) at phase end, the MP4 pulled via the **existing goadb device-file GetFile path** (`Device.OpenRead` — the "adb pull" wire, the reciprocal of the committed-APK "OpenWrite" push in install.go), with evidence rows emitted through the shared `#EvidenceRow` envelope. Implemented over the runner's GENERIC background-session service (plugin-check's compiled-in `verb:session` seam); NO core changes.

- **schema/adb.cue** — the method enum gains `session`; new fields action (start|stop|status), session_id, state_dir, artifact_dir, log_dir, venue, phase. params/cue_types_gen.go regenerated via the spec cue:gen pipeline (schemagen concat -pkg=params → cue exp gengotypes → retag) — **byte-idempotence proven** (regeneration reproduces the committed file exactly, before and after the change).
- **provider.go** — session dispatch before the method dispatcher — builds an sdk.NewCheckContext (the reverse-leg one-dial) and calls runSession with the provider-resolved device endpoint; the session never dials (the recorder owns the wire).
- **session_method.go** — the provider-facing bracket over the generic background-session service: spawn/stop/status requests submitted over the **existing InvokeProvider reverse leg** (ClassVerb "session", OpExecute) — spawns no process, knows no transport. Bounded evidence-row wait on stop.
- **record.go + cmd/serve** (`CHARLY_ADB_RECORDER=1`) — the detached recorder launches the device-side screenrecord (nohup screenrecord --time-limit 1800 /sdcard/<id>.mp4 >/dev/null 2>&1 &), verifies the capture file appeared, holds the session, and on SIGTERM stops it (SIGINT via pkill), waits for the MP4 size to stabilize (moov finalize), pulls it via the GetFile path into state_dir/<session>.mp4, and finalizes the FINAL marker + the evidence row.json (instrument/origin/verb/venue/phase/artifact[kind "mp4"]). A failed stop still finalizes an artifact-less row — a capture failure is visible, never a phantom.
- **ADE** — charly.yml plan gains adb-session-start / adb-session-status / adb-session-stop lifecycle checks; description updated to the 13-method surface.
- **Pins** — sdk v0.2026241.933 → v0.2026248.1237 + spec v0.2026241.931 → v0.2026248.1234 (the session seam's CheckContext.InvokeProvider contract; same pins as plugin-vnc #4).

A NEW test fixture proves the changed runtime path over a real wire: `goadb_server_test.go` — a minimal **goadb SERVER** stub (host:transport selection, raw shell, the sync STAT/RECV sub-protocol) on a real TCP socket; `TestRunSessionRecorderAgainstRealGoadbServer` runs the recorder end to end against it (dial via the exact `adbDeviceForAddr` path the recorder uses → shell start → SIGINT stop → STAT finalize detection → RECV GetFile pull → evidence finalize). The goadb wire path cannot be exercised by the fakeDevice tests.
