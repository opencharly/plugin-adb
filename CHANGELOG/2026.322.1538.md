# 2026.322.1538 — ci: run this module's Go gates so the params gate can fail

## Summary

`candy/plugin-adb/params_repro_test.go` (merged as #21) gates the committed `params/cue_types_gen.go` against the canonical generator, but **nothing ran it**: this repo carried only `tag-on-merge.yml`, and the org-required `validate / validate` is a thin caller of `pr-validator.yml` (review + check-run gate) which never runs a repo's `go test`.

This adds `.github/workflows/ci.yml` — the module's four Go gates (`gofmt`, `go vet`, `go build`, `go test`) on push, pull request and dispatch, in the same order the contract module runs them: formatting and compilation are reported before test output, because a test result means nothing before the build is green.

The step shape is the established one in this org (`plugin-qdrant`'s `ci.yml`), so this is the second occurrence of a pattern rather than a new mechanism; the file must live in each repo, so it cannot be shared.

Scope is deliberately one file. No Go source, no schema, no wire shape, no generated artifact changes.
