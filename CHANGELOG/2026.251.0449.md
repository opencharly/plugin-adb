# 2026.251.0449 — fix(test): TestRunSessionCaptureEndToEnd — deterministic start-wait replaces the 30ms fixed-sleep (R1 flake)

## Summary

R1 flake fix: `TestRunSessionCaptureEndToEnd` closed the SIGTERM-analog `done` channel after a **fixed 30ms sleep** racing the goroutine's start. Under CI load a starved goroutine can reach `close(done)` before `runSessionCapture` starts the bracket, finalizing at 0 bytes and failing the byte-count assert — intermittent. Replaced with the deterministic pattern the row-first test (`TestRunSessionCaptureFinalizesRowBeforePull`) already uses: poll the fake's mutex-protected invocation log for the `nohup screenrecord` launch (5s correctness deadline, 10ms ticks), then close `done`. No timing luck — the start is provably underway before the stop analog.
